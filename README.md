# ⚽ KickOff - Football Booking System

Applicazione web full-stack per la gestione e prenotazione di campi sportivi.

Il progetto permette agli utenti di visualizzare i campi disponibili e effettuare prenotazioni tramite una piattaforma web.

## 🚀 Tecnologie utilizzate

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- REST API

### Frontend
- Angular
- TypeScript
- Bootstrap
